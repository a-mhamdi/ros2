# Contents

This directory contains the laboratory material used throughout the **ROS 2** course. Each lab is provided in two formats:

- **Typst source files (`.typ`)**: the original lab documents used to write and maintain the course material.
- **PDF files (`.pdf`)**: compiled versions of the Typst sources that can be viewed or printed without requiring additional tools.

Typst is a modern typesetting system designed as a fast and user-friendly alternative to LaTeX. For more information, visit the official website:

👉 https://typst.app/

### `py-onramp` Notebooks

The directory also includes interactive Jupyter/Marimo notebooks that complement the lab sessions. An introductory Python notebook intended as a quick refresher for students with limited Python experience. It covers the essential language constructs and programming concepts required before starting **ROS 2** development.

- Open in Google Colab [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/a-mhamdi/ros2/blob/main/Labs/py-onramp.ipynb)
- Open in Molab [![Open in molab](https://marimo.io/molab-shield.svg)](https://molab.marimo.io/github/a-mhamdi/ros2/blob/main/Labs/py-onramp.py)

### `shell-scripting.md`

It introduces common shell commands, scripting techniques, environment variables, loops, conditionals, and automation workflows that are frequently used when working with Linux-based robotics systems and **ROS 2**.
